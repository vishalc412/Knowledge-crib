## Scope — what this does NOT claim

The over-extension to guard against is reading this as "cross-principal disclosure is closed". It is not closed by default: local admission mints memory-1 and `resolveStrictPrincipal` (recall.ts:373–377) returns false when the switch is unset, so an ordinarily configured shared store still admits every unstamped private record to `get`, `history`, `ledger`, `audit`, `supersede`, `delete` and `placementsOf`. Nor does this claim the TEAM ledger is scoped: both predicates carve unstamped team records in deliberately (api.ts:4235, `if (source === 'team') return true;`), because that ledger is committed and append-only. Nor that decisions and feedback are principal-scoped — `gatherRecall` documents the boundary as scoping the RECORD pool only (recall.ts:474). Nor that audit F03 is fully closed: the record states F03 closed only the STAMPED case and that its Action named this unstamped remainder (docs/audits/2026-09-05/launch-audit.md:136 and :142, with remediation status at :8).

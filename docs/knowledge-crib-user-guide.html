Knowledge-crib Team User Guide

A portable "project soul" for AI coding agents — a local-first, git-committable knowledge graph of your codebase, served to any agent (Claude Code, Cursor, GitHub Copilot, Codex) over one MCP server. Full architectural context in far fewer tokens; no more architecture-breaking edits.

1. What it is

AI coding agents re-read files every session to rebuild context — slow, token-hungry, and blind to architecture. Knowledge-crib indexes a project once into a queryable graph (the soul, stored in .crib/ and committed with the repo), then serves it to any agent over MCP.

The one-sentence model: Parse → graph → persist as a committable soul → build a fast local index → serve to agents over MCP.
  • Deterministic core — AST extraction across 9 languages (TypeScript/JS, Java, C#, Go, Rust, PHP, Python, PL/SQL, Markdown). No model call, fully offline.
  • Provenance-tagged — every edge carries EXTRACTED or INFERRED + confidence + evidence, so agents can filter to facts.
  • Token-bounded — every verb result respects limits with truncated/cursor paging.
  • Optional LLM layer — your IDE's model (never the server) authors a semantic graph on top: purposes, invariants, business rules, flows. Grounding-validated and secret-scanned before persist.

2. Install (one-time per machine)

Requirements: Node ≥ 22.5, pnpm 9.15.0 via Corepack, macOS/Linux.

git clone <knowledge-crib repo>
cd knowledge-crib
corepack pnpm@9.15.0 install
corepack pnpm@9.15.0 build            # builds all 7 packages

corepack pnpm@9.15.0 setup            # one-time: global bin dir on PATH (then restart terminal)
corepack pnpm@9.15.0 --dir packages/cli link --global

which crib && crib --help             # verify

The global link points at the repo's dist/ — upgrading is git pull && corepack pnpm@9.15.0 build, no reinstall.

3. Five-minute quickstart (per project)

cd /path/to/your/project
crib init .        # index + git hooks + IDE MCP wiring + next-steps hero
crib doctor .      # ✓/✗ health: node / corepack / indexed / freshness / hooks / IDE wiring

crib init does everything in one shot. crib doctor tells you exactly what is broken and how to fix it (exit 1 on failure — safe for CI).

Commit the soul. .crib/ is chunked JSONL — diff-friendly and engine-free — so the whole team shares one soul and every agent sees the same graph. Keep .crib/index/ (derived SQLite) in .gitignore; commit the rest.

6. The LLM semantic layer (optional, high value)

The server never calls a model. Your IDE's LLM is the author; the server hands it grounded seed data and validates what comes back (grounding check + secret scan) before persisting. Built bottom-up: symbol → file → cluster → system.

crib skill install          # bundle the /crib-enrich skill into ~/.claude/skills
# then in Claude Code:  /crib-enrich   (one token-packed batch per turn, bottom-up)

Headless, from the CLI:

crib enrich --status                              # coverage + next layer
crib enrich --next [--budget-tokens 24000]        # one token-packed grounded batch
crib enrich --save ./batch.json                   # validate + persist authored items
crib enrich --auto [--max-tokens N] [--max-batches N]   # bounded autonomous loop
crib enrich --prune-stale [--apply]               # clean artifacts whose targets left the soul
crib audit-llm .                                  # re-verify everything; non-zero exit on drift

Once artifacts exist, query/context/dossier fold a lightweight LLM pointer per hit (~7.7× smaller than the full blob); pass withLlm: true to get the full analysis + semantic graph + evidence.

7. Visualize & export

crib viz . --port 43127                         # offline web UI (compound cluster graph)
crib export --format graph.json . > graph.json  # full soul as one JSON
crib export --format report .                   # human-readable counts summary
crib export --format mermaid --procedure <id> . # CFG mermaid for one procedure
crib export --format rules --procedure <id> .   # decision table

8. Troubleshooting

SymptomFix

ERR_PNPM_NO_GLOBAL_BIN_DIR on linkcorepack pnpm@9.15.0 setup, restart terminal, retry
Index slow on a huge repoScope it: --exclude vendor,generated or --package <name> (monorepo)
Stale results after editscrib update . (or install hooks for automatic refresh)

# Knowledge-crib 30-second teaser

Build the local video:

```sh
node media/teaser/render.mjs
```

Output:

- `dist/media/knowledge-crib-teaser-30s.mp4` — 1920×1080, 30 fps, H.264/AAC.
- `dist/media/knowledge-crib-teaser-thumbnail.png` — graph UI still.

Seven scenes, 30 seconds total: problem, deterministic indexing, system map, module context, capability members, symbol/source with opt-in 2-hop context, and product boundaries. Middle drill-down views are code-native, generic product visuals. No customer-specific UI capture or domain names. Music is original and generated locally by `soundtrack.mjs` (132 BPM techno).

The teaser deliberately makes bounded claims: deterministic core and local-first storage; LLM enrichment is optional; it does not replace engineering judgement or invent evidence.
